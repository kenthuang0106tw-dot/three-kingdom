# NEXT TASK

## M11 / Task 11.1 — Post-M10 Product Direction Selection

### Why this task

M10 is closed without a second playable character after three bounded Zhang Fei hypotheses failed their frozen tactical-distinction gates. The project should not silently start Zhao Yun, a second Stage, another Zhang Fei rescue, or an unrelated backlog item. The next highest-value step is one planning decision that selects the next player-visible product goal from the existing backlog and gives it an ordered, testable scope.

### Completion conditions

- Revalidate the M10 closeout decision and the released Guan Yu-only production baseline.
- Inventory the eligible P1/P2 product directions without implementing any of them.
- Compare at least the second Stage, a future playable-general track, and focused release-quality/content work by player value, dependency readiness, asset cost, technical risk, and expected rework.
- Select exactly one next milestone goal and define its exclusions, dependency order, deliverables, acceptance criteria, and first implementation task.
- Keep Zhang Fei deferred unless explicit product-owner authority supplies the revised gameplay / identity / art contract required by Task 10.5F.
- Update Roadmap, Sprint, Backlog, Checklist, Technical Debt, and NEXT_TASK.
- Make no runtime, gameplay, art, asset, build configuration, Stage, Enemy, Boss, Camera, input, Audio, UI, or React change.

### Validation

- focused documentation contract test
- `pnpm test`
- `pnpm typecheck`
- `pnpm lint`
- `pnpm build`
- `pnpm build:github-pages`
- verify the production manifest and runtime remain unchanged

### Expected files

- one concise M11 product-direction decision record
- `GAME_ROADMAP.md`
- `SPRINT.md`
- `BACKLOG.md`
- `CHECKLIST.md`
- `TECH_DEBT.md`
- `NEXT_TASK.md`
- one focused planning contract test

### Risks

- Treating deferred Zhang Fei assets as a reason to restart implementation.
- Selecting Zhao Yun or a second Stage without comparing dependency and art costs.
- Mixing multiple player-visible goals into one milestone.
- Turning a planning task into speculative architecture or gameplay work.

Do not implement Zhang Fei, Zhao Yun, character selection, a second Stage, new art, or any gameplay feature in this task.
