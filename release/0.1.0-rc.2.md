# Three Kingdoms 0.1.0-rc.2

Status: Release Candidate for M9.3 platform acceptance; not the final release.

## Identity

- Version: `0.1.0-rc.2`
- Tag: `v0.1.0-rc.2`
- Source commit: `72bb680932f8ce95057e06f8e207f4ad4665e7bb`
- Node: `v24.14.0`
- Package manager: `pnpm@11.7.0`
- Manifest: `release/0.1.0-rc.2.manifest.json`

RC2 supersedes RC1 because Windows builds copied JSON/XML runtime files with
CRLF while GitHub Actions deployed LF. The game content was identical, but the
artifact hashes were not portable. RC2 packages those runtime text assets as
LF on every platform and leaves binary assets unchanged.

Both outputs preserve the same 52-file canonical production runtime inventory.
Vinext still generates deployment UUIDs and a prerender secret, so its exact
artifact hash is retained while its declared reproducible hash normalizes only
those values. GitHub Pages requires no manifest normalization.

## Deployment equivalence

Before RC2 was named, the corrected local GitHub Pages output was compared
byte-for-byte with all 57 files on the existing public deployment. All 57
matched. This proves the public URL serves the same production artifact bytes
even though its workflow metadata names the earlier content-equivalent commit.
RC2 is not claimed as a new deployment; it is a new immutable source identity
for those verified bytes.
